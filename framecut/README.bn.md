# Framecut Studio ব্যবহার

বাংলায় ব্রিফ দাও, ফুটেজ থাকলে চ্যাটে যোগ করো, আর আউটপুট কী চাও জানাও। যেমন, “এই স্ক্রিন রেকর্ডিংয়ের ২ থেকে ৮ সেকেন্ড রাখো। মূল অডিও রাখবে। সংযুক্ত SRT-র সময় নতুন ক্লিপের শুরু থেকে ধরা। ফলটা MP4 দাও।”

## GitHub লিংক দিয়ে যোগ করা

এই সংস্করণের রেপো প্রকাশিত হলে ChatGPT-কে তার লিংক দিয়ে বলো, “এই রেপোর Framecut Studio প্লাগইনটি দেখো। এখানে প্লাগইন যোগ করার সুবিধা থাকলে framecut-tools থেকে framecut-studio ইনস্টল করে নামটা যাচাই করো।” কেবল লিংক পড়া আর ইনস্টল করার ধাপ আলাদা। প্লাগইনের আসল ডিরেক্টরি plugins/framecut-studio। মূল রেপোর skills/ ফোল্ডারটি HeyGen-এর সংস্করণ।

ডেস্কটপে স্থানীয় প্লাগইন ইনস্টলের সুবিধা থাকলে রেপোটি খুলে Framecut Tools থেকে Framecut Studio বেছে নাও। CLI ব্যবহার করলে আনজিপ করা রেপোর রুটে চালাও।

    codex plugin marketplace add .
    codex plugin add framecut-studio@framecut-tools

প্লাগইন ZIP গ্রহণ করে এমন ইন্টারফেসে আলাদা framecut-studio-plugin.zip ব্যবহার করো। প্লাগইন বাছাইয়ের সুবিধা না থাকলে এই রেপো খুলে কাজের নির্দেশনা অনুসরণ করা যায়। অ্যাকাউন্টের স্থায়ী স্কিল তালিকায় যোগ হওয়ার দাবি করার আগে তালিকায় নাম দেখো।

## প্রথম ভিডিও

“Framecut Studio দিয়ে ‘দৃশ্যপট’ নামে ৪ সেকেন্ডের বাংলা টাইটেল বানাও। নিচে লিখবে ‘রেখা থেকে গতি’। শেষে MP4 দাও।”

“এই পণ্যটার তিনটি স্ক্রিনশট দিয়ে ১৫ সেকেন্ডের ৯:১৬ লঞ্চ ফিল্ম বানাও। প্রথমে সমস্যাটা দেখাও, তারপর স্ক্রিনশটে সমাধান, শেষে ২ সেকেন্ড লোগো রাখো। MP4 আর এডিটযোগ্য প্রজেক্ট দাও।”

বহু দৃশ্য, অ্যানিমেশন ও কম্পোজিটিংয়ের জন্য Node 22+, npm, FFmpeg ও চালু হতে পারে এমন Chrome লাগে। সাধারণ টাইটেল, কাট ও SRT বসাতে Python 3 এবং libass ও libx264-সহ FFmpeg যথেষ্ট। বাংলা ফন্ট প্যাকেজে আছে। নতুন ফুটেজ, অ্যাভাটার বা কণ্ঠ সংশ্লেষের জন্য সংশ্লিষ্ট মিডিয়া সেবার অ্যাক্সেস লাগতে পারে।

## নমুনা ও পরীক্ষা

title-card.mp4 হলো FFmpeg দিয়ে তৈরি চার সেকেন্ডের নমুনা। captioned-cut.mp4 একই ভিডিওর ০.৫ থেকে ২.৫ সেকেন্ড অংশে বাংলা সাবটাইটেল বসানোর ফল। HTML-ভিত্তিক অ্যানিমেশনের আলাদা এডিটযোগ্য উদাহরণ আছে প্লাগইনের skills/hyperframes/starter/ ফোল্ডারে। এই তিনটি একসঙ্গে দেখে কীভাবে কোন কাজটি হয় বোঝা যাবে।
