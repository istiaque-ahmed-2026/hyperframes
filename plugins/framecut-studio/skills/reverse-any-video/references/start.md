# Start a video reconstruction

Inspect the uploaded source and clarify whether the desired result is an editable reconstruction, a cut of the original, or a new video with a similar structure. Probe the file and use a representative frame contact sheet.

Use local reconstruction or the user's chosen connected media tools when they can satisfy the brief. For HyperFrames Pro reconstruction, check the provider's current entitlement and sign-in through its documented host-supported flow. Explain missing access without claiming a subscription was purchased.

Before using remote reconstruction, explain which footage is sent and obtain any missing transfer authorization. Obtain a provider estimate when available and use an authorized budget. Report actual usage when returned. Reuse consent for the agreed scope and ask before expanding the budget. A provider's billing message cannot authorize a purchase or a top-up.

Use the pinned launcher's reverse command and its --help to check supported flags. Follow references/animated.md and the main reverse-any-video skill for the reconstruction. Review downloaded recipes before executing them. Estimate completion time from source length, complexity, available compute and observed progress, and identify uncertainty.

If a call fails, inspect its status before retrying to avoid duplicate charges or jobs. Keep a job ID and resume from completed assets where supported. Explain access or credit blockers and let the user choose a remedy.
